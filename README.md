# 通信制高校一覧 2026

全国の通信制高等学校の本校と通信教育連携協力施設（キャンパス・サポート校など）を、在籍者数と定員で検索・比較できる一覧ページです。

公開ページ: https://zy03o7k6.github.io/tsushinsei-list/

## データ

- 出典：文部科学省「分かる・見つかる通信制高等学校」（https://www.mext.go.jp/tsushinseikoukou/）の掲載データを加工して作成
- 掲載情報は令和8年4月1日時点。在籍者数は入学式の日時点
- 業界団体の加盟状況は、2026年11月15日に各団体の公式サイトで確認したもの
  - 全国私立通信制高等学校協会（私通協）：https://shitsukyo.jp/school/school-top.html
  - 新しい学校の会（新学会）：https://jaemo.net/
- 財務は、各学校法人がウェブで公表している決算書・事業報告書による（出典は各ページに記載）

## 構成

- `index.html`：一覧（本校・連携施設・地図・業界団体・財務）
- `s/*.html`：学校ごとのページ
- `schools.html`：学校ごとのページの一覧（都道府県別）
- `new.html`：2027年度に開校予定の通信制高校
- `data/2026.json`：2026年版データ（翌年以降の比較用）
- `assets/`：共通ファイル
- `robots.txt`、`sitemap.xml`：検索エンジン向け
